
# Текущие проблемы и риски
* Синхронные запросы - зависимость от скорости ответа от страховых компаний
* Проблемы при росте количества страховых компаний
* Потенциально при неработоспособности одного АПИ - не будут выгруженны данные
* Долгое ожидание ответов
* Потенциальная неконсистентность данных из-за разных интервалов обновления
